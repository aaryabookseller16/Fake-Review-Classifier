Conservative by accident,
not by design.

The model produces fewer false positives than false negatives—a useful tendency for moderation, where accusing a real customer is the costlier error. A production system should tune that trade-off explicitly.

Under the bonnet

Four lines of maths.
No black box.

Adaline learns a linear decision boundary by minimising mean squared error. The optimisation is written from scratch in NumPy; scikit-learn supplies only pipeline plumbing and the comparison baseline.

Objective

L(w,b) = 1/n Σ (yᵢ − (xᵢᵀw + b))²

A differentiable, convex loss surface with a global optimum—provided the learning rate is stable.

adaline.pyPython
errors = y - self.activation(
    self.net_input(X)
)
self.w_ += self.lr * 2.0 * (
    X.T @ errors
) / n_samples
self.b_ += self.lr * 2.0 * errors.mean()
A

Sparse by necessity

The TF-IDF matrix would need roughly 35 GB if densified. Every operation preserves SciPy sparse matrices end to end.

B

Divergence fails loudly

A large learning rate can explode while remaining a finite float. Explicit guards reject the run instead of returning silent garbage.

C

Limits are part of the result

One dataset, one GPT-2 generator, one split. This is a research demonstration—not a universal truth machine.
